# Tuần 05

Bài tập cá nhân tuần 05 môn Lập trình Thiết bị Di động.

## Danh sách bài tập

| Bài | Nội dung | Kiến thức chính |
|-----|----------|-----------------|
| [Bài 01 - FirebaseAuth](./FirebaseAuth/) | Xây dựng luồng đăng nhập Google và hồ sơ người dùng | Firebase Authentication, Credential Manager, Jetpack Compose |
| [Bài 02 - UTHAuth](./UTHAuth/) | Mở rộng đăng nhập và quản lý công việc theo tài khoản | Realtime Database, Firebase Analytics, Remote Config |

Mở từng project trong Android Studio. Đặt cấu hình Firebase Android của package `com.example.firebaseauth` vào `app/google-services.json` trong project cần chạy.
