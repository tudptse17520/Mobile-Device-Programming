# Tuần 06 — Lập trình thiết bị di động

Ba bài tập được tổ chức thành ba project Android Studio độc lập, viết bằng Kotlin và Jetpack Compose:

| Project | Nội dung |
|---|---|
| [UTHSmartTasks](./UTHSmartTasks/) | UTH Todo V2: giao diện, mock REST API, nhắc việc và Google sign-in |
| [DevicePermissions](./DevicePermissions/) | Nâng cao 01: luồng xin quyền vị trí, thông báo và camera |
| [CryptoMarket](./CryptoMarket/) | Nâng cao 02: dashboard giá crypto, nhiều API đồng thời và cập nhật định kỳ |

Bài thực hành REST API trước đó của Tuần 06 nằm trong [ProductApp](./ProductApp/). Project hiển thị chi tiết sản phẩm bằng Retrofit và Jetpack Compose.

Mở từng thư mục project riêng trong Android Studio. Hướng dẫn build và cấu hình cục bộ nằm trong README của mỗi project.
